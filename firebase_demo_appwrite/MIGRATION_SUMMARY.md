## ⚠️ Action Required

### Create Storage Bucket

You need to create a storage bucket in your AppWrite console:

1. Go to https://cloud.appwrite.io/console
2. Select project `690e997d000355680a8e`
3. Navigate to **Storage** → **Create Bucket**
4. Note the **Bucket ID**
5. Set permissions:
   - Role: `Users` or `Any`
   - Permissions: `Create`, `Read`

### Update Bucket ID

Open `lib/services/appwrite_client.dart` and replace:

```dart
static const String bucketId = 'YOUR_BUCKET_ID_HERE';
```

With your actual bucket ID:

```dart
static const String bucketId = 'your-actual-bucket-id';
```

## API Comparison

| Feature             | Firebase                             | AppWrite                                               |
| ------------------- | ------------------------------------ | ------------------------------------------------------ |
| **Anonymous Auth**  | `FirebaseAuth.signInAnonymously()`   | `Account.createAnonymousSession()`                     |
| **Upload File**     | `ref.putData()` returns `UploadTask` | `Storage.createFile()` returns `Future<File>`          |
| **Upload Progress** | `UploadTask.snapshotEvents` stream   | Not directly available (use loading indicator)         |
| **Download URL**    | `ref.getDownloadURL()`               | `Storage.getFileView()` or `Storage.getFileDownload()` |
| **User ID**         | `user.uid`                           | `user.$id`                                             |

---

## Key Differences

### Upload Progress

- **Firebase:** Real-time upload progress via `UploadTask.snapshotEvents`
- **AppWrite:** No built-in progress tracking; shows simple loading indicator

### File References

- **Firebase:** Uses path-based references (e.g., `uploads/file.pdf`)
- **AppWrite:** Uses unique file IDs generated by the SDK

### Permissions

- **Firebase:** Storage rules configured in Firebase Console
- **AppWrite:** Bucket-level permissions set per role/user
